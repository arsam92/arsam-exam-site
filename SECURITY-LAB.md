# Security Lab Brief

This repository is a deliberately insecure, static training exercise. All accounts, exams, answers and results are fictional. There is no backend and no connection to any real school or learning system.

## Learner objectives

Try to identify the risks created by:

1. Authentication and role decisions performed entirely in browser code.
2. Sensitive exam answer data delivered to the browser before the student starts.
3. Admin-created records and scores being kept in editable browser storage.
4. A video UI that hides its download action even though the media is served as a public static file.

## Safe boundaries

- Only test this repository or a local copy.
- Do not try these techniques against third-party services or real student accounts.
- Do not add real personal data, credentials, live answer keys, or private media.
- This exercise is not a production-ready assessment platform.
